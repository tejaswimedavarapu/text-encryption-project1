# Text Encryption Using Cryptographic Algorithms

## Project Description
This project demonstrates secure text encryption and decryption using the AES-256-CBC cryptographic algorithm in Node.js. The application encrypts plain text into unreadable cipher text and decrypts it back to the original message using a secure encryption key.

---

## Features
- AES-256-CBC Encryption
- Secure Text Decryption
- Random IV (Initialization Vector) Generation
- Unique encrypted output for same input
- Node.js Crypto Module Implementation

---

## Technologies Used
- JavaScript
- Node.js
- Crypto Module
